## Instruções de uso

1. Abra o arquivo `index.html` no navegador ou execute o projeto em um servidor local.
2. Na tela inicial, pressione `ENTER` ou `ESPAÇO` para iniciar o jogo.
3. Use as setas do teclado para controlar a peça:
	- `←` e `→` para mover para os lados
	- `↓` para descer mais rápido
	- `W` ou `↑` para rotacionar
4. Complete linhas horizontais para ganhar pontos.
5. Quando aparecer a tela de fim de jogo, pressione `ENTER` ou `ESPAÇO` para reiniciar.
